## B01 — Gemini Health cannot revert user manual choice
- Owner: `application/services/gemini_keys.py`, `application/ports/gemini_keys.py`, `infrastructure/persistence/sqlite_gemini_key_repository.py`.
- Added field-limited repository `update_health`: conditional SQL UPDATE of status, last_checked_at, detail on a still-existing key; no insert/upsert/is_active/label/fingerprint/masked_key write.
- Service serializes latest request version for each key and declines outdated response rights; SQL field limits preserve activation even during overlap.
- Tests `tests/integration/test_gemini_keys_foundation.py`:
  - T01: health A completion after B activation leaves B active.
  - T02: health B begins inactive then B activated before completion; stays active.
  - T03: deleted row cannot be resurrected by a late health completion.
  - T04: older same-key health completion cannot overwrite newer result.
- Additional real Qt Gemini Keys view regression `tests/ui/test_gemini_keys_view.py`.
- Keyring masking and manually selected key semantics unchanged.

## B02 — Agent cannot post stale answers/errors on wrong Scene
- Owner: `presentation/main_window.py`.
- Each Agent request receives immutable request_id + episode_id + scene_id + context_generation.
- Per-task signal bridge sends identity with success and error. Window accepts only active identity matching displayed context and not closing.
- Navigation, project/Scene refresh, relevant UI change, and close retire old callbacks and do not release newer request busy state.
- Per-task signal emitter is not parented to closing QMainWindow, preventing destruction of an emitter still owned by an in-flight QRunnable.
- Qt regressions in `tests/ui/test_gemini_agent_workspace.py` cover:
  - T05: stale success and failure from A not shown in B;
  - T06: B busy remains true while A finishes;
  - T07: same SCENE_001 on different episodes remains isolated;
  - T08: close/destroy window while request runs does not crash/raise from a deleted signal sender.
- Existing Qt heartbeat/no-blocking test retained.
